# Dairee — website

A static marketing site for Dairee, a biomaterials company that turns surplus dairy into a plastic-free, leather-like material.

- `index.html` — page markup (hero, about, stats, process, material, applications, impact, quote, partners, contact, footer)
- `styles.css` — design tokens and layout (responsive, reduced-motion aware)
- `script.js` — sticky header, mobile menu, scroll reveals, stat count-up, contact form handling

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

The contact and newsletter forms are front-end only; connect them to a form service or backend before launch.
Copy, stats (other than global milk-waste figures) and the "Curd™" material name are placeholders to replace with real data.
